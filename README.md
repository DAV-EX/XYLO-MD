## 🛠️ FEATURE DEEP DIVE

*Keep the README clean. Expand the nodes below to inspect system protocols.*

<details>
<summary><b>[+] Sub-Bot Rental System </b></summary>
<br>

Spawn fully operational clone bots directly from within XYLO-MD:
*   `.rentbot <number> [days]` — Spawn a sub-bot, get pairing code.
*   `.listrental` — List all active sub-bots with status & expiry.
*   `.removerent <number>` — Disconnect & wipe a sub-bot instantly.
</details>

<details>
<summary><b>[+] Economy Engine & Perk System</b></summary>
<br>

A deep virtual economy built into every interaction with a **13-Level Perk System (Lv.5 → Lv.100)**:
*   **Lv. 5:** 1.1× earning multiplier
*   **Lv. 40:** 1.5× earning multiplier
*   **Lv. 100:** 2.0× earning · Legendary title
</details>

<details>
<summary><b>[+] Group Security Suite</b></summary>
<br>

Military-grade protection against group manipulation:
*   Anti-Link, Anti-Spam, Anti-Raid, Anti-Sticker, Anti-Delete.
*   Warning System with configurable thresholds + auto kick/ban/mute.
</details>

<details>
<summary><b>[+] P2P Loan System</b></summary>
<br>

*   Borrow from the system (5% interest/day) or P2P lending.
*   Overdue penalty: +2% rate per overdue day.
*   Auto-deduction runs every hour.
</details>
